# 启示录战争｜满天繁星，举目皆敌

**Apocalypse War** · Stellaris 4.5.x

这是一个战狂模组，兼容UI大修和伞的暗蓝UI，推荐在原版环境游玩。

简要概括就是半步武灾的复仇。

你将扮演一个离飞升只差一步的武灾国家，在启动以太相的时候，以太相被堕落和它们的爪牙破坏，因此你没有飞升成功，后座力只破坏了半个河系，其他国家对你的好感是负一千，同时因为这次以太相的波动，虚境和现实的联系被斩断，河系里再也没有人可以选择灵能飞升，更是吸引了寰宇深处一些存在的目光。

选择对堕落的态度，可以让它们强制觉醒并立刻开战，无事发生，或者以羞辱为借口向堕落宣战。

开局可以设置舰容和指挥上限，来自一个改舰容前玩家的怨念。

设置5年后的小天灾，不影响真正的天灾。

加强堕落，只对舰队武器伤害、舰船装甲、护盾有影响。

选择资源产出修正，众志成城加产出，超兽战士的异能量不会超过心中的信念.jpg，千手观音能够维持帝国产出不受影响，恢复民生会导致产出减半，可以通过局势消除。

迟来的舰队，前两个就是字面意思，获得舰队或者获得资源，第三个进入叛逃者事件。

超频法令，可以让发动帝国公民的主观能动性，快速完成建设。

母星存在以太相遗址，可以配合超频法令可以快速结束游戏。

在星海深处会生成哨站，L星门旁有擎天堡。

帝国领土的周围会生成一些半拉巨构，等待玩家重建。

按理来说开局的凝聚力是足够点满传统的，括弧原版环境下，要是加上传统槽位扩展就不行了。

设定上半飞升的玩家帝国拥有了控制台的力量，所以放手去做吧，才不是因为没有做平衡，只能靠控制台兜底呢。

第三天会卡一会，卡顿是正常的，在升格前超光和给科技，请耐心等待

## 下载

仓库的 `release/` 按版本分目录，每个版本里两个压缩包，按需下载其中一个即可，**不要同时安装**。

- `Apocalypse_War_Local.zip`：解压到 `Documents/Paradox Interactive/Stellaris/mod/`，启动器启用
- `Apocalypse_War_Workshop.zip`：创意工坊上传用包，内容与本地版相同

### Apocalypse_War_Workshop.zip

与 Steam 创意工坊版本完全一致。

- 内容：`apocalypse_war/` 文件夹（内含 `descriptor.mod`）
- 用途：上传创意工坊，或直接放进 `Documents/Paradox Interactive/Stellaris/mod/` 由启动器识别
- 不含本地加载用的 `.mod` 入口文件

### Apocalypse_War_Local.zip

纯粹的本地安装版。

- 内容：`apocalypse_war/` 文件夹 + `apocalypse_war.mod`
- 用途：解压后把 `apocalypse_war` 和 `apocalypse_war.mod` 一起放进 `Documents/Paradox Interactive/Stellaris/mod/`，启动器播放集中启用
- `.mod` 内使用相对路径 `path="mod/apocalypse_war"`

### 安装后的目录

```
Documents/Paradox Interactive/Stellaris/mod/
├─ apocalypse_war/
└─ apocalypse_war.mod        （仅本地版需要）
```

### 注意

- 两个版本内容相同，只是打包方式不同
- 已订阅工坊版的玩家不需要下载压缩包

## 安装

### 工坊

在 Steam 创意工坊订阅后，于启动器播放集中启用。

### 本地

1. 把 `apocalypse_war` 文件夹放进 `Documents/Paradox Interactive/Stellaris/mod/`
2. 把 `apocalypse_war.mod` 一并放进 `mod/`
3. 启动器播放集里启用
